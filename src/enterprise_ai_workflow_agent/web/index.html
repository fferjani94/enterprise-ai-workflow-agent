      How OpsPilot works

      A bounded agent loop over read-only business tools, with safeguards that keep answers tied to retrieved records.

      1. 1

        Question

        You describe a customer problem in plain language.

      2. 2

        Agent

        A LangGraph loop asks a local Ollama model which tool to call, up to a fixed number of rounds.

      3. 3

        MCP tools

        Five read-only tools query accounts, tickets, products, and knowledge documents.

      4. 4

        Verified answer

        The answer is returned with the retrieved records and the full tool trace.

      Safeguards

      • Tools are read-only. The agent cannot change any data.
      • Record IDs must come from an earlier tool result. Unverified IDs are rejected and logged in the timeline.
      • If an answer cites an ID that no tool returned, it is replaced by the retrieved records.
      • Tool rounds, calls per round, result size, and total run time are all capped.
      • Evidence is checked by rules, not by a model. It reduces unsupported claims but does not guarantee correctness, so review the evidence yourself.

      Available tools

      • search_accounts find customer accounts by name
      • get_account_tickets list support tickets for an account
      • get_ticket_details read a single ticket
      • get_product_information read product version and description
      • search_knowledge search product documentation

      The demo database contains synthetic data only: Northstar Labs and Bluebird Commerce as customers, and the CloudDesk and FlowSync products.
